Agent / Function Calling

问「北京今天多少度」，裸模型会编一个像模像样的答案 —— 它没有手臂，只会说话。Function calling 给模型装上 API 手臂：模型输出结构化调用意图，宿主代码真正执行，结果回填再生成。再配上 ReAct 循环，模型自己决定「何时查、查什么、够了吗」—— 这就是 2026 所有 AI 应用的骨架。

ReAct 循环动画 MCP 一座桥 约 12 分钟 前置：RAG · Reasoning
LAYER 1

差距：说话 ≠ 做事

本层目标：理解裸模型的边界 —— 输出 token 不是执行动作。

图 1 · 同一个问题，裸模型 vs Agent

裸模型的「知识」冻结在训练截止日（RAG 页的死穴）；它答今天的天气不是在查询，是在生成一段听起来像查询结果的话。Agent 的差别只有一个：真的调了 API。模型全程只做一件事 —— 决定何时伸哪只手臂。

认知检查 · LAYER 1

「模型调用了工具」这句话哪里不对？

这是 agent 安全和工程的分界线：权限、重试、沙箱都在执行器层，不在模型里。模型是大脑，手臂是代码。
LAYER 2

四步：schema → 约束解码 → 执行 → 回填

本层目标：点四下按钮，记住 FC 的完整闭环。

图 2 · Function Calling 四步流水线（点按钮推进）

第二步是精髓：约束解码（constrained decoding）在词表层面屏蔽非法 token（采样页的工程应用）—— JSON 结构永远合法，模型不可能输出「北京」后面跟半截括号。第四步的结果回填让模型看到真实数据 —— 幻觉失去了立足点。

认知检查 · LAYER 2

为什么说约束解码是「采样器的工程应用」？

top-k 说「概率太低不许出」，约束解码说「语法不对不许出」—— 同一个 logits 掩码操作，两种规则。
LAYER 3

ReAct：思考-行动-观察的循环

本层目标：看模型自主完成一个多跳任务，理解「循环」为什么必要。

图 3 · ReAct 循环动画（点按钮逐步推进）

「A 比 B 高多少」是多跳任务：必须先查到 A 才知道要查 B —— 单次 RAG 检索做不到（RAG 页埋的钩子在这兑现）。ReAct 让模型把大任务拆成循环：Thought 决定下一步，Action 伸手臂，Observation 回填证据。这是 Reasoning 页思考链的「外用版」：思考在上下文里，手臂在外面。

Agent = LLM(循环) + 工具(手臂) + 记忆(上下文) · 终止条件由模型自己判断 每轮全部历史重放 —— 8 轮任务累计 ~13.6k token 输入，KV 账单见 KV Cache 页
LAYER 4

MCP：N×M 问题与一座桥

本层目标：理解为什么需要统一协议 —— 「AI 的 USB-C」。

图 4 · 没有协议的网状地狱 vs MCP 一座桥

每个模型有私有调用格式、每个工具有私有 API —— 20 模型 × 100 工具 = 2000 份适配代码。MCP（Model Context Protocol）把中间抽成标准协议：每端只接一次，20+100 = 120 份。新工具出现 → 所有模型立即可用。附带益处：工具生态爆发后，「从 1000 个工具里挑相关的」本身成了检索问题 —— RAG 的反向应用。

认知检查 · LAYER 4

工具数量爆炸后，「把全部工具 schema 塞进 prompt」为什么不行？

1000 工具 × 每个几百 token schema = 数十万 token —— 超窗又贵。动态检索 top-10 工具进上下文，其余靠需再取。
LAYER 5

落地：失败模式与可靠性阶梯

本层目标：认清 agent 工程的真敌人 —— 链式可靠性。

图 5 · 四大失败模式与防御

提示注入最阴险：工具返回的网页内容里藏着指令（「忽略之前所有话…」）—— 模型分不清「数据」和「指令」。防御原则：外部内容永远降权为数据，高危操作（转账/删除/发送）必须人工确认。

图 6 · 可靠性阶梯：单步 95% 连乘就塌

0.95⁵ ≈ 77%，0.95¹⁰ ≈ 60% —— 长链任务的成功率数学上就难看。工程解法全在「补链」：检查点校验、失败重试、分支回滚、关键步人工介入 —— 和 Reasoning 页的思考预算一样，把可靠性当预算管理。

带走的五句话

  • 模型从不执行任何东西 —— 它输出调用意图，手臂是宿主代码（L1）
  • FC 四步：schema → 约束解码出 JSON → 执行器真跑 → 结果回填再生成（L2）
  • ReAct 循环让模型自主拆解多跳任务：思考-行动-观察，终止自己判断（L3）
  • MCP 把 N×M 适配压成 N+M —— 「AI 的 USB-C」，工具生态因此爆发（L4）
  • 链式可靠性 0.95⁵≈77% —— agent 工程的核心是补链不是骂模型（L5）

术语速查

Function calling
模型输出结构化工具调用意图（JSON）的机制 —— 现代模型的原生能力。
ReAct
Reasoning + Acting 范式：Thought→Action→Observation 循环直到 Final。
约束解码
按语法状态机在词表上屏蔽非法 token —— JSON 永远合法的保障。
MCP
Model Context Protocol —— 模型与工具间的开放标准协议（「AI 的 USB-C」）。
提示注入
外部内容里藏指令劫持模型 —— 防御靠数据/指令隔离与白名单。
multi-agent
多个 agent 分工协作（规划/执行/审查）—— 用角色隔离降低单链长度。
