DEEP LEARNING · MECHANISM

Attention 机制

一台「可微分的查字典机器」，如何长成 GPT 的大脑、ViT 的眼睛、CLIP 的翻译官。这一页从你每天都在做的「联想检索」出发，走到 Attention is All You Need 的那行公式。

五层认知 3 个交互演示 ≈ 25 分钟 前置：向量点积
LAYER 1

直觉：你的大脑在软查字典

本层目标：不出现任何公式，建立核心直觉 —— 按相关性，把多条信息按比例混合。

有人说「attention 就是聚光灯」—— 只关注重要的、忽略无关的。这个比喻对了一半，但漏掉了最关键的动作：关注之后发生了什么。光「看着」没用，大脑是把被看到的东西按各自的相关程度加权融合成一个新的理解。

真正贴切的类比是查字典。你在纸上写下一个词，去字典里找释义 —— 这是「硬查找」：精确命中一个条目，取出一条释义，完事。但大脑的检索不是这样的。听到「小奶猫」，你的脑海里浮现的不是某一个精确条目，而是毛茸茸、小小只、会呼噜——它同时「点亮」了猫、幼崽、可爱……多个条目，每个条目点亮的程度不同，最后融合成一个综合印象。

核心直觉：Attention = 软查找。输入一个「查询」，不精确命中某一条，而是给字典里所有条目各打一个相关度分数，然后按分数加权平均，把所有内容融合成输出。分数就是「注意力」。

为什么偏偏要「软」？两个理由，一个是天然的，一个是致命的：

语义本身是模糊的

「小家伙」该精确对应猫还是狗？都不对，也都对。语义检索天生需要「部分匹配、多处取材」—— 硬查找直接宕机，软加权天然合身。

硬查找不可求导

argmax（只选最强的）是个台阶函数：分数变一点点，输出从这条释义整个跳到另一条 —— 梯度为零，梯度下降学不动。softmax 是 argmax 的光滑替身，可微分的查找才能被训练。这一步是深度学习的生死线。

最后把场景换到句子上，你会看到同样的戏码：句子 The animal didn't cross the street because it was too tired —— it 指的是谁？人脑瞬间完成一次「软查找」：扫一遍前文，animal 相关度爆表，street 相关度很低，于是 it 的语义被 animal 浸染。Transformer 里的 attention 做的就是这件事，只不过用的「相关度」是向量点积。这一幕在 LAYER 2 的 DEMO 3 里会亲眼看到。

认知检查 · LAYER 1

相比「精确命中一个条目、取出一条释义」的硬查找，软查找最不可替代的性质是？

软查找不一定「更准」（它输出的是混合物），也不一定更快 —— 它赢在可微：相关度分数连续地影响输出，梯度才流动得起来。这是「查字典」能被塞进神经网络的前提。
LAYER 2

可视化：点积打分，softmax 分权

本层目标：亲眼操作「相关度怎么算（点积）→ 分数怎么变成权重（softmax）→ 权重怎么混合内容（加权平均）」三步 —— 整个 Attention 就这三步。

2.1第一步：点积 = 相似度打分

把每个词想成平面上的一个箭头（方向 = 语义）。两个箭头有多「合得来」？点积给出答案：方向一致 → 大正分；垂直 → 零分（无关）；相反 → 负分（语义相反）。拖动下面的滑块旋转你的「查询」箭头，看分数实时变化：

DEMO 1 · 点积打分器（查询 q 旋转，5 个词条实时打分）

左：语义平面上的 5 个词条（箭头）与查询（亮色）。右：各词条得分。softmax 之后分数变成「分蛋糕」—— 每根条只关心自己占总分多少，方向最合的那根拿走大头的注意力。注意负分：softmax 后它仍分到一点权重，但几乎可以忽略。

2.2第二步 + 第三步：权重分配，加权混合

拿到权重后干什么？按权重把所有内容向量加权平均，得到输出。这是「软查字典」的完整动作。下面这台机器里，字典有 5 个条目，每个条目有「索引向量 k」（用来被打分）和「内容向量 v」（被打完分后拿来混合）。换查询、调锐度，看输出星标落点：

DEMO 2 · 软查找机器（q 打分 → softmax 分权 → 加权平均出结果）

★ = 输出（加权平均的结果）。两个方向玩透：换查询 —— 星标漂向不同的条目群，「毛绒小可爱」落在小猫和幼犬之间；拉锐度 —— 锐度 20 时星标几乎钉死在单个条目上（退化成硬查找 argmax），锐度 0.5 时星标塌向所有条点的中心（退化成无差别平均）。Attention 的「软硬」程度是一个连续旋钮。

容易忽略的点：查询和条目用的是两套向量 —— 索引 k 负责「被找到」，内容 v 负责「被取用」。就像字典：目录页（按拼音排序）和释义页（实际内容）是两套系统。这个词是什么（k）和它携带什么（v）可以不一样 —— 这是后面 QKV 三矩阵的伏笔。

2.3词与词互相查：it 到底指谁？

把软查找升级：句子里每个词同时是查询和字典条目 —— 每个词都拿自己当 q，去查所有词的 k，然后按权重混合所有词的 v，得到自己的新表示。这就是自注意力（self-attention）。经典考题来了：

DEMO 3 · 自注意力热力图（行 = 查询词，列 = 被查词，亮 = 注意力强）
橙色框 = 「it」那一行

认知检查 · LAYER 2

DEMO 2 中把锐度拉到最低（τ 很大），输出会变成什么？这说明什么？

softmax(x/τ) 在 τ→∞ 时趋近均匀分布。锐度是注意力的「聚光程度」：太钝 → 什么都看 = 什么都没看；太锐 → 不可微、训不动。真实模型里的锐度由点积大小和 1/√d 缩放共同决定（LAYER 3 讲为什么）。
LAYER 3

数学：三步翻译成一行公式

本层目标：把 L2 的三步操作逐项翻译成符号，最终汇成 Attention(Q,K,V) = softmax(QKᵀ/√d)V，并搞懂三个设计决定。

3.1三步，三个式子

设查询向量 q，字典有 n 个条目，索引为 k₁…kₙ、内容为 v₁…vₙ。L2 的三步：

sᵢ = q·kᵢ   →   wᵢ = esᵢ / Σⱼ esⱼ   →   out = Σᵢ wᵢ·vᵢ 打分 → softmax 分权 → 加权平均。与 DEMO 2 逐帧对应

3.2为什么要有 Q、K、V 三个矩阵？

DEMOS 用的词向量是「一个向量演三个角色」。但一个词作为查询（我要找什么）、作为索引（我能被谁找到）、作为内容（我实际提供什么），语义侧重完全不同 —— 「苹果」作为 k 应该同时能被「水果」和「手机」找到，作为 v 应该分别提供不同的信息。解决方案：给同一个词向量 x 配三张可学习的投影矩阵：

q = xWQ,   k = xWK,   v = xWV 让网络自己学出「这个词在找什么 / 能被什么找到 / 该贡献什么」三种分身

把句子所有词的 q 堆成矩阵 Q、k 堆成 K、v 堆成 V，三步合并 —— 所有查询对所有条目的打分恰是一次矩阵乘法 QKᵀ：

Attention(Q, K, V) = softmax( QKᵀ / √dk ) · V 2017 年《Attention is All You Need》的全部核心 —— 现在你可以逐符号讲出它在做什么

3.3设计决定一：为什么除以 √d？

设 q、k 各分量独立、均值 0、方差 1，则点积 q·k 的方差是 d（每一项贡献方差 1，共 d 项）。维度越高，分数的绝对值越大 —— d=64 时分数轻松冲到 ±8，softmax 被推入饱和区：权重近似 one-hot，梯度几乎为零，训练死掉。除以 √d 恰好把方差归一回 1，让 softmax 保持在「有梯度」的灵敏区。一行字：缩放 = 给 softmax 上保险。

3.4设计决定二：因果掩码

GPT 生成第 t 个词时只能看前文。做法简单粗暴：把 QKᵀ 矩阵中「未来位置」的分数设为 −∞，softmax 后权重自然为 0。这就是因果掩码（causal mask） —— 训练时一次并行算完所有位置，却严格保持「不许偷看未来」。注意力机制本身对顺序无感（L4 会看到这一点有多深刻），掩码是「时间方向」被显式焊进结构的地方。

深究：多头注意力（Multi-Head）—— 几台投影仪同时打光

一组 QKV 只能学出一种「相关性模式」（比如句法依存）。但词与词的关系是多姿多彩的：指代、修饰、主题、位置邻近…… 做法：并行跑 h 组独立的低维注意力（d→d/h），每组在自己的子空间里学一种模式，最后拼接：

MultiHead(Q,K,V) = Concat(head₁,…,headₕ)WO

代价不变（各头维度缩小），表达力翻 h 倍。Transformer-base 用 8 头，GPT-3 用 96 头 —— 相当于 96 台投影仪从不同角度同时给句子打光，各自聚焦不同的关系结构。

认知检查 · LAYER 3

如果把公式里的 √d 缩放去掉，用 512 维的向量直接做 QKᵀ，最可能发生什么？

方差 d=512 意味着分数典型值 ±22 —— softmax 在这个量级下完全饱和。反向传播时 softmax 的雅可比矩阵趋近零矩阵，梯度断流。除以 √d 不是装饰，是让高维注意力「活下来」的急救措施。
LAYER 4

抽象：一台可微分的字典查询机

本层目标：跳出 Transformer 语境，用「内存寻址」和「集合」两只眼睛重新看 attention —— 认知升维。

4.1视角一：内容寻址的软内存

计算机的 RAM 按地址取数：给你门牌号，取这个格子。还有一类罕见的硬件 CAM（内容寻址存储器）：给你内容，并行比对所有格子，命中的亮灯。Attention 就是 CAM 的软件版 + 两个升级：

按内容并行比对

q 与所有 k 同时算点积 —— 不是逐格翻找，而是一次矩阵乘法全体打分。O(n) 个条目、一次并行，这是它配得上大规模的原因。

软读出 + 可学习

CAM 硬命中一个格子；attention 软读取所有格子并加权融合 —— 且 k、v 由训练塑造：WK、WV 在学「怎么建索引、存什么内容」。字典本身是长出来的。

这个视角下，L2 的锐度滑块就是 τ→0 退化回硬 CAM、τ→∞ 退化成平均池化的连续谱。Attention 是「查找」与「平均」之间的可微插值，插值位置由网络自己学 —— 这句话在 2014 年神经图灵机（NTM）里被首次明说，后来的 Transformer 是它的工业化版本。

4.2视角二：它根本看不见顺序

一个深刻到容易被忽略的事实：把输入词打乱，attention 输出的集合只是跟着打乱 —— 注意力对排列等变（permutation-equivariant），本身完全不感知顺序。证据就在公式里：只有点积（对称、无位置信息）和加权求和，没有任何一处知道「谁在第几个」。

于是位置编码（positional encoding）不是锦上添花，是补上一块结构性缺失：把「第 i 个」这个信息当作向量加进词嵌入，模型才看得见词序。「我打他」和「他打我」的差别，全部由位置编码扛进来的。

再往深看一层：attention 把输入当作一个集合（set）处理 —— 谁来都行、多少个都行、什么模态都行（词、图像块、蛋白质残基、音频帧……只要能变成向量）。这就是它成为「万物路由器」的结构原因。

4.3视角三：全连接图上的消息传递

把 n 个 token 画成 n 个节点，attention 矩阵就是一张带权有向完全图：每条边权重 = 注意力，动态、内容决定、可学习。一层 attention = 图上一轮「所有节点向所有节点发消息、按权重收消息」。层数 = 消息传递的跳数：一层只能看一步邻居的信息混合，L 层才能把 L 步外的信息搬运过来。GNN 是稀疏版这条路，Transformer 是全连接版这条路 —— 同一个抽象的两种密度。

换好眼睛之后

  • 字典 / 内存视角：attention = 可学习的内容寻址软内存（L4.1）
  • 集合视角：attention 天生顺序盲，位置编码是结构补丁（L4.2）
  • 图视角：一层 = 全连接图上一轮消息传递，层数 = 信息搬运跳数（L4.3）
认知检查 · LAYER 4

把「我 打 他」换成「他 打 我」喂给一个没有位置编码的自注意力层，输出会怎样？

没有位置信息时，「我打他」和「他打我」是同一个 multiset —— attention 是排列等变的，分不清谁打谁。BERT/GPT 能懂语序，靠的全是位置编码（或 RoPE 这类旋转式位置注入）。
LAYER 5

应用：一个机制，长出整个物种树

本层目标：看清 GPT、ViT、CLIP、检索系统背后是同一台软查找机器 —— 模式识别。

GPT / 大语言模型 —— 堆 96 层软字典

因果掩码自注意力 × 几十层 + 前馈层 = 下一词预测机器。每一层，每个 token 都重演一遍 DEMO 3：按相关性重新混合上下文，层层精炼。上下文窗口 = 字典的规模，注意力是它唯一的「读到上文」的通道。

ViT —— 图像切块当词用

图像切成 16×16 小块 → 每块一个向量 → 序列进 Transformer。「它看不见顺序」的集合本性在这里反而是优势：块与块的关系由内容决定。注意力矩阵于是可视化出「这只鸟的头部在看翅膀」级别的结构。

CLIP / 跨模态检索 —— 字典比喻的字面实现

文本向量当 q，去查一整个图库的 k —— q·k 打分、softmax 排序。「以文搜图」就是注意力公式的裸奔版：没有 V 矩阵，只留打分。同一台机器，字典从「句子里的词」换成了「全网的图」。

RAG / 向量数据库 —— 检索即注意力

把知识切块、算嵌入、存进库；提问时用问题向量查最相关的 k 块，塞进上下文。本质是两层注意力：外层（数据库检索）硬一点，内层（LLM 读上下文）软一点 —— 你的每一次「联网回答」都是这台机器在运转。

AlphaFold —— 氨基酸互相「看」

蛋白质折叠的核心模块也是 attention：残基 i 与残基 j 的注意力 = 结构上的靠近倾向。氨基酸序列 = token 序列，3D 结构 = 注意力图层层精炼后的产物。生物学问题的最优解，出现在一个 NLP 机制里。

代价：O(n²) 与它的赎罪券

每个 token 查所有 token —— 计算与显存随长度平方膨胀。长上下文的军备竞赛全是这一条的赎罪：稀疏注意力、FlashAttention（不换数学只换 IO）、线性注意力、状态空间模型（Mamba）……理解了平方从哪来（QKᵀ 的形状），你就看得懂每一篇加速论文在砍哪一刀。

所有应用共享同一个模式：把一堆东西变成向量 → 按内容互相打分 → 按分数路由信息。模态（文字/图像/蛋白质）只是向量的产地不同。

带走的五句话

  • Attention = 软查找：打分（点积）→ 分权（softmax）→ 混合（加权平均）（L1-L2）
  • Q/K/V 三矩阵 = 一个词的三种分身：找什么 / 被谁找到 / 贡献什么（L3）
  • Attention(Q,K,V) = softmax(QKᵀ/√d)V；√d 防饱和、掩码锁因果（L3）
  • 它是可微的内容寻址内存、顺序盲的集合算子、全连接图上的消息传递 —— 三个视角同一台机器（L4）
  • 从 GPT 到 AlphaFold，一切 = 向量化 + 打分 + 路由；唯一的原罪是 O(n²)（L5）
