训练地基 · loss 的物理含义

交叉熵与困惑度

Pretraining 页的「猜下一个词」、Scaling Laws 页整条 power law 曲线、Quantization 页的 PPL 5.7→5.9 —— 全站在同一个目标函数上运行了 30 多页：交叉熵 = −log P(正确词)。这一页打开它：loss 的单位是 bits/token（信息量），PPL（困惑度）= 2^loss —— 「模型每一步在几个词里犹豫」。看完这页，所有训练曲线的纵轴都有了读法。

真·训练循环模拟器 surprisal 赌局 约 8 分钟 前置：Pretraining · Sampling
LAYER 1

赌局：−log P 的计分直觉

本层目标：对「重罚」建立手感。

图 1 · surprisal 计分表：猜对概率 vs 罚分（bits）

「猜下一个词」是一场赌局，计分规则 surprisal = −log₂P：全押对（P=1）零罚分；一半对（P=0.5）罚 1 bit；只敢押 1% 的冷门词却对了 —— 罚 6.64 bits（node 实算）。曲线形状是关键：概率趋近 1 时罚分平缓趋零，概率趋近 0 时罚分爆炸 —— 对模型的训练信号就是这句话：把概率质量押给真正会出现的词，押得越准罚分越少。loss = 全语料每个位置 surprisal 的平均。

认知检查 · LAYER 1

模型给正确词的概率是 0.01（但说对了），surprisal 罚多少？这说明优化器「想」干什么？

这就是「压缩」： surprisal 是描述这件事所需的最短编码长度 —— 模型越会猜，语料就能压得越短。
LAYER 2

公式：从 logits 到分数的流水线

本层目标：认清全站的同一个流水线。

图 2 · logits → softmax → 取正确词 → −log₂

四步流水线：总线状态 × lm_head → logits → softmax(·/T) → 概率 → −log₂P(正确词)。前半段你已经在 残差流页（读出器）和 Sampling 页（softmax）见过 —— 同一个函数，三页三种用法：Sampling 页用温度 T 调尖度（生成多样性）、Attention 页用 √d 防饱和（梯度健康）、幻觉页 T→0.1 看错误峰值 —— 本页只把它当计分器读数。梯度也美：∂loss/∂logit = p − onehot —— 概率减去正确答案的 one-hot，错多少补多少，下一层亲手转它。

认知检查 · LAYER 2

梯度 ∂loss/∂logit = p − onehot(正确词)，物理含义是？

softmax 的分母让全表梯度之和为 0 —— 搬家不增不减。下一层的训练模拟器就是这个式子在转。
LAYER 3

训练：25 步真梯度下降

本层目标：亲眼看着 loss 下降、概率搬家。

图 3 · 玩具训练循环（8 词表，lr=0.4，点按钮单步执行）

不是动画 —— 是真的在跑梯度下降（与 node 验证脚本同一段代码）：8 个词、正确词 idx2、初始 logits 全 0（均匀分布）。每次点击执行 p − onehot 更新：step 0 loss = 3.00 bits（= log₂8，均匀瞎猜），step 6 过半（50.9%），step 24 loss 0.18、P(正确词) 88.4%。「loss 下降」的机制第一次肉眼可见：概率质量从均匀摊开一步步搬到正确词上 —— 预训练的本质是同一件事在万亿 token 上做，只是「正确词」每步都在换。

认知检查 · LAYER 3

初始 loss 恰好是 3.00 bits —— 为什么？

任何模型开局都在 log₂(词表) 附近 —— Llama-3 词表 128k 的开局线是 17 bits（Tokenizer 页那个 17 的另一重身份）。
LAYER 4

换算：PPL = 2^loss 的读法

本层目标：会读论文和量化表里的 PPL。

图 4 · 同一条 loss 曲线的两种纵轴

PPL = 2^loss（bits 口径）—— 把「平均罚分」翻译成人话：「每一步在几个等价词里犹豫」。对账（node 实算）：loss 3.0 = PPL 8；Quantization 页的 PPL 5.7 = loss 2.51 bits —— 每步在 5.7 个词里犹豫，量化到 4bit（5.9）犹豫只多 0.2 个词，这就是「≈免费」的含义。旗舰级模型 ≈ 2.0-2.5 bits/token = 把语料压到 1/4 ~ 1/6 —— loss 的单位就是压缩率，Tokenizer 页 17 bits 是天花板（均匀瞎猜），压缩即智能的数学实体。

认知检查 · LAYER 4

PPL 从 5.7 涨到 5.9（4bit 量化），为什么说「几乎免费」？

读 PPL 表的正确姿势：永远在脑内做一次 log₂ —— 对数尺度上判断贵贱。
LAYER 5

统一：全站的对数账本

本层目标：认出所有出现过的 log 亲戚。

图 5 · 凡是比较两个分布，都是这个公式

对账表：Scaling 页整条 L(C) 曲线的纵轴就是交叉熵（10 倍算力换 11% 相对 loss 降，现在你知道降的单位是 bits/token）；RLHF 页的 KL 缰绳 = Σp·log(p/q)（node 实算例 0.133 bits）—— 同一个 log 家族在「别跑太远」里的用法；Sampling/Attention/幻觉三页的 softmax 温度是同一函数的生成侧用法；Tokenizer 17 bits / Pretraining 压缩即智能 / Chinchilla tok/param 全部以 bits 计价。LLM 训练的全部叙事 = 在对数刻度上做微积分 —— 这就是那条下降曲线的全部含义。

认知检查 · LAYER 5

KL 散度、交叉熵、surprisal 三者的关系？

单点 → 平均 → 与理想编码的差：同一个 log，三种记账方式。

带走的五句话

  • 交叉熵 = −log₂P(正确词)：surprisal 赌局，P=0.01 罚 6.64 bits（L1）
  • 梯度 = p − onehot：「错多少补多少」，概率质量守恒搬家（L2）
  • 开局 loss = log₂(词表)：均匀瞎猜 3 bits（8 词）/ 17 bits（128k）（L3）
  • PPL = 2^loss：5.7 = 每步在 5.7 个词里犹豫 = 压缩到 1/5.7（L4）
  • KL/温度/Scaling 纵轴全是 log 家族 —— 训练叙事在对数刻度上展开（L5）

术语速查

交叉熵 (cross-entropy)
H = −Σ p·log q，此处退化为 −log P(正确词) —— 预训练的 loss 函数。
surprisal / 自信息
−log₂p：单次事件的信息量 —— 罕见事件携带更多信息。
困惑度 (perplexity, PPL)
2^loss —— 「每步在几个等价词里犹豫」的人话翻译。
bits/token
loss 的单位 —— 每个词平均需要的编码长度，压缩率的倒数。
KL 散度
两个分布差的 bits 计价 —— RLHF 缰绳、蒸馏损失的同族公式。
熵 (entropy)
分布自身的最小平均编码长度 —— 交叉熵的下界（不可压缩部分）。
teacher forcing
训练时用真实答案（非模型输出）作为下一步输入 —— 每个位置都有监督信号的前提。
