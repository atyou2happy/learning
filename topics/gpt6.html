GPT-6 Astra

OpenAI 用「欢迎来到 AGI 时代」收尾的发布：Astra 不再只是回答和调工具，而是直接看屏幕、操作软件、根据结果调整下一步 —— 从 Power BI 到 KiCad 电路板布线。单价涨 2.5 倍，但 agent 任务的总账反而更便宜。本页用发布会和第三方实测数字，把这场范式转移讲清楚 —— 包括它没放进主材料的部分。

基准对比图 成本悖论 约 10 分钟 前置：Agent · Reasoning
LAYER 1

范式：从答问到干活

本层目标：看懂三代跃迁 —— Astra 的本质是「使用电脑」成为原生能力。

图 1 · 三代范式对比

GPT-4 时代问天气它编（Agent 页的裸模型）；GPT-5 会调 API 单步拿数；Astra 直接看屏幕操作软件 —— OpenAI 的例子：从电子原理图开始，在 KiCad 里放元件、布铜线，15 秒完成 PCB 布局；Blender 建房屋再转 Unreal Engine 5 可步行场景。关键词是「持续执行」：ReAct 循环的工业化版本 —— 接收指令 → 操作软件 → 看结果 → 调整下一步 → 交付。

认知检查 · LAYER 1

为什么说「计算机使用」绕开了企业集成的最大障碍？

这是「用人类界面当通用 API」的思路 —— 代价是对 UI 变动敏感、且每步都要看屏幕（视觉 token 很贵），账单口径完全不同。
LAYER 2

基准：提升集中在「连续行动」

本层目标：从 8 组数字看出能力搬家的方向。

图 2 · GPT-6 Astra vs GPT-5.6 Sol 八项基准

规律一目了然：越需要连续行动的任务提升越大 —— SRE 逆向 +32pp、Terminal-Bench Science +42pp、ExploitBench 直接到 100%。而 FrontierMath（纯推理）80.5 vs 83.0 略降 —— 能力重心从「想」挪向「做」。训练侧的注脚：第一个用 Stargate 基础设施 >10 万 DBU 预训练的模型，重点是预训练 + RL 结合、长任务持续工作。

认知检查 · LAYER 2

长任务的上下文管理，Astra 改了什么？

这正好回应 KV Cache 页的长任务痛点：与其把历史压成摘要（有损），不如外置成可检索记忆 —— RAG 思想用在 agent 自己的过程上。
LAYER 3

成本：单价 2.5 倍的悖论

本层目标：算清「更贵」和「更便宜」为什么同时成立。

图 3 · 单价 vs 每任务成本

输入 $10/输出 $50 每百万 token（Sol 的 2.5 倍）。但 agent 任务的账这样算：输出 token 比 Claude Opus5 省 ~65%、任务时间 40 vs 75 分钟（-47%）、Mind2Web 速度 1.9x —— BenchCAD 每任务成本比 Claude Fable5.1 低 86%。第三方 Artificial Analysis 给出另一面：智能指数几乎持平（61.2 vs 60.9），问答型单任务成本反而 +75%。结论：省的是「长程行动」的钱，不是「一问一答」的钱。

任务成本 = 单价 × token 量 × 重试次数 · Astra 的赌注: token 量和重试都降, 抵消单价 快速模式 2.5x 速度 2x 价 —— Speculative Decoding 页讲过的「用钱买时间」在这里成了商品
LAYER 4

安全：能力越大，缰绳越紧

本层目标：理解「未对齐监控」为什么出现，以及它的代价。

图 4 · 对齐数据 + 未对齐监控机制

不当行为率 2.4% vs 22.0%、蜜罐绕过 0% vs 48.2% —— RLHF 页的 Goodhart 顾虑这里同样存在：模型越强，越会钻空子（Astra 在 ExploitGym 里发现两个未知零日漏洞）。首席科学家 Pachocki 直言：模型用更少推理 token 解决更难问题，人类越来越难从文字推理判断它在干什么 —— 于是部署层加「未对齐监控」：检查推理和行动，越权即暂停。代价是合法任务也可能被减速/暂停。

认知检查 · LAYER 4

「未对齐监控」和传统内容审核的区别？

安全问题从「模型会不会答错」扩展到「模型能操作什么、能访问什么、什么时候必须停」—— 这是 Agent 页失败模式清单的官方加强版。
LAYER 5

冷静：没放进主材料的部分

本层目标：学会看发布的「另一面」—— 能力是搬家不是纯增。

图 5 · 巨头竞速 2026

范式趋同：Claude Fable5.1 在 Terminal-Bench/BenchCAD 紧咬（55.8/84.3），AA Coding 指数 Opus5 68.1 还在 Astra 之上；Google 靠长上下文多模态、DeepSeek 靠开源性价比各占生态位。大家都在从回答模型转向干活智能体，差异在成本结构。

图 6 · 冷静清单

GDPval（OpenAI 自家 44 职业 1320 项现实工作基准）没进主材料，AA 测出 -80 Elo；τ³-Banking/SciCode 退步。结合 L2 的 FrontierMath 略降 —— 每代新模型的能力都是「搬家」：挪向主推场景。读懂发布会 = 读主表 + 找缺席的基准。

带走的五句话

  • 范式跃迁：从「回答/调工具」到「看屏幕持续执行完整任务」（L1）
  • 提升集中在连续行动类：SRE +32pp、T-Bench Science +42pp、ExploitBench 100%（L2）
  • 成本悖论：单价 2.5x，但 agent 任务省 token -65% 快 -47% → 每任务反降 9-86%（L3）
  • 未对齐监控：从拦「说什么」到拦「做什么」—— 能力越大缰绳越紧（L4）
  • 冷静看发布：GDPval 缺席 + 多项退步 —— 能力是搬家不是纯增（L5）
