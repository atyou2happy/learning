Mamba / SSM

KV Cache 的账单无限增长：128k 上下文 = 64GB，每 token 都留一份永不删除的档案。Mamba 反其道而行：固定大小的隐状态，永不长大 —— 128k 时与 KV Cache 差 8000 倍。这是与 KV Cache 页的终极对照：记忆的两种代价 —— 精确但臃肿 vs 有损但恒定。2026 的答案是：都要（hybrid）。

状态增长滑块 吞吐曲线 约 10 分钟 前置：KV Cache · Attention
LAYER 1

账单：记忆能不能不长大？

本层目标：重看 KV Cache 的账单，提出全站压轴的问题。

图 1 · KV Cache 的线性账单

KV Cache 页的口径：7B MHA 每 token 0.5MB×32 层 —— 1k=0.5GB 温和，128k=64GB 离谱，而且这份账单随对话进行实时增长（分页只能管理不能阻止）。人类不是这样记事的：读一本小说不会让脑子变大一倍。问题来了： Transformer 的记忆为什么必须「全文保存」？—— 因为 attention 要精确回看每一个 token，删掉任何一个都可能改变输出。

认知检查 · LAYER 1

为什么 Transformer 不像人一样「压缩记忆」？

精确性是 attention 的天赋也是枷锁。想压缩就得换数学 —— 这正是 SSM 的入场券。
LAYER 2

恒定：RNN 的老思想换了新引擎

本层目标：理解递归状态 + 为什么 RNN 死了而 SSM 活了。

图 2 · 状态增长对比（拖序列长度滑块！）
4k tok

蓝线 KV Cache 随长度线性爬升；绿线 Mamba 状态恒定 0.008GB —— 拖到 128k：64GB vs 0.008GB，8000 倍。状态大小与序列长度完全解耦。

图 3 · 递归：一个公式装下全部历史

h_t = A·h_{t−1} + B·x_t —— 老式 RNN 的骨架：历史被「蒸馏」进固定大小的状态。但 RNN 死于训练无法并行（h_t 依赖 h_{t−1}，必须串行走完 T 步）。SSM 的复活术：线性系统的整段展开可以写成卷积形式 —— 训练时一次并行算完所有位置（像 attention 页的掩码并行一样），推理时切回递归形态享受恒定状态。训练用并行形态、推理用递归形态 —— 两头的好处全占。

训练形态: 卷积 (并行, 像 attention) · 推理形态: 递归 (恒定, 像 RNN) · 同一组参数两种展开 Mamba 的选择性打破了卷积形式 —— 用并行扫描 (parallel scan, O(log T)) 补回并行性, 硬件感知实现是论文的核心工程贡献
LAYER 3

选择：该记的记，该忘的忘

本层目标：理解 Mamba 对经典 SSM 的关键改造。

图 4 · Δt 步长看输入下菜

经典 S4 的 A/B/C 参数固定 —— 对莎士比亚和代码用同一副记忆策略；Mamba 让它们依赖输入：「2024」「营收」大步写入（Δ 大），「的」「嗯」几乎跳过（Δ 小）。与 LSTM 门控神似，但 SSM 版本保住了训练并行性 —— 2020 代的数学给了 1990 代的想法一副新身体。

认知检查 · LAYER 3

「选择性」解决了 S4 的什么缺陷？

压缩的前提是取舍，取舍的前提是知道内容重要不重要 —— 固定参数的 SSM 只有压缩没有取舍，选择性补上了这块拼图。
LAYER 4

吞吐：长短序列的分水岭

本层目标：从计算账理解两条吞吐曲线的交叉。

图 5 · 吞吐 vs 序列长度

attention 每 token 回看全部历史（计算 ∝ L），Mamba 每步只碰固定状态（计算恒定）。计算账：L=128k 时 attention 每 token 537M 次乘加 vs Mamba 恒定 0.3M —— 2000 倍差距，论文口径长序列吞吐 ~5x。短序列反过来：attention 的精确匹配在检索/上下文学习类任务上碾压 —— RAG 页那种「找回第 3 个 chunk 的原文」正是 SSM 的死穴（历史已被有损压缩，回不来了）。

LAYER 5

混搭：2026 的现实答案

本层目标：记住 hybrid 配比与决策表，完成与全站的合流。

图 6 · Jamba 层带 + 决策表

Jamba（AI21, 52B）的答案：1 个 attention : 7 个 Mamba —— 少量 attention 层保住精确检索，大量 Mamba 层享受恒定状态，256k 上下文。AirLLM 页跑的 Qwen3.8-27B 用的 Gated DeltaNet 也是这个家族（线性注意力）。Mamba-2 的 SSD 算法更进一步：把 SSM 与 attention 统一进一个数学框架 —— 界限还在模糊，「谁取代谁」正变成「怎么配比」。

带走的五句话

  • KV Cache 线性增长（128k=64GB）—— attention 精确回看的天赋是账单的枷锁（L1）
  • SSM 状态恒定 0.008GB：128k 时差 8000 倍 —— 训练并行（卷积）+ 推理递归两头像（L2）
  • Mamba = 选择性：A/B/C 看输入下菜，该记的记该忘的忘（L3）
  • 吞吐分水岭：长序列计算差 2000 倍（~5x 实测），精确检索是 SSM 死穴（L4）
  • 2026 现实是 hybrid：Jamba 1:7、DeltaNet 家族 —— 配比取代站队（L5）

术语速查

SSM (状态空间模型)
用递归状态 h_t = A·h + B·x 建模序列 —— 记忆固定大小的连续系统。
选择性 (selectivity)
Mamba 的核心：状态转移参数依赖输入 —— 内容感知的记住/遗忘。
并行扫描 (parallel scan)
O(log T) 计算递归链的树形算法 —— 选择性 SSM 保住训练并行的关键。
d_state
每通道状态维度（典型 16）—— Mamba 的「记忆容量」旋钮。
hybrid 架构
attention 层与 SSM/线性注意力层混排 —— Jamba 1:7 是代表配方。
SSD (Mamba-2)
状态空间对偶 —— 把 SSM 与 attention 统一进半可分矩阵框架。
Gated DeltaNet
门控增量规则网络（线性注意力家族）—— Qwen3.8-27B 采用。
