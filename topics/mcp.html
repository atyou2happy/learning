MCP 协议

Agent 页讲了「会用工具的模型」，这页讲工具是怎么接上去的。M 个模型 × N 个工具 = M×N 份胶水代码的地狱，被一层开放协议解成 M+N —— 和 USB-C 干的是同一件事：谁都不为谁定制，都只为协议实现。2024-11 Anthropic 开源，2025 OpenAI/Google 跟进，2026 已成事实标准。你每天用的 AI 应用，架构图就是这页。

总线对比图 协议四步动画 约 8 分钟 前置：Agent
LAYER 1

死结：M×N 集成地狱

本层目标：感受没有协议时的连接爆炸。

图 1 · 5 个模型 × 8 个工具

每个模型要接每个工具：5×8=40 份定制胶水。规模到 20 模型 × 50 工具就是 1000 份。更痛的是边际成本：每出一个新模型，要重写全部 N 个集成；每出一个新工具，全部 M 个应用各改一遍 —— 集成工作量随生态平方级增长，这是 2024 之前 agent 开发的真实痛感。

LAYER 2

总线：M+N 的 USB-C 魔法

本层目标：理解「为协议实现」如何把平方降为线性。

图 2 · MCP 居中，各连一边

模型侧实现一次 client，工具侧实现一次 server —— 5+8=13 份，省 68%；20×50 规模省 93%。边际成本也崩了：新模型只需 1 份 client（全部服务器零改动），新工具只需 1 份 server（全部模型立刻可用）。这就是 USB-C 的思想：安卓苹果耳机显示器谁都不为谁定制 —— 插座统一了，世界就通了。

认知检查 · LAYER 2

为什么「标准协议」通常由行业共同维护而不是某家私有 API？

USB、HTTP、以太网的历史一再重演：协议赢得生态，生态赢得时代。
LAYER 3

协议：四步接线

本层目标：点按钮走完 discover → list → prompt → call。

图 3 · 协议四步（点按钮推进）

底层是 JSON-RPC 2.0：① server/discover 摸清版本与能力（2026-07-28 版起协议无状态化——每个请求自带 _meta，发现结果可缓存）② tools/list 返回工具卡：name + description + inputSchema（JSON Schema） ③ host 把工具卡塞进 system prompt —— 这就是模型「看到的」toolbox ④ 模型吐 tool_call → host 路由执行 → 结果回填对话。

图 4 · 三原语 + 一个反向

Server 能给三样：Tools（执行动作）、Resources（读数据）、Prompts（模板）。Client 反向给一样：Elicitation（server 问用户「确认删除？」—— 危险动作的人肉刹车）。2026-07-28 版已废弃 sampling（server 反向借 LLM）—— 新实现直接调 LLM API，协议回归纯粹的「上下文管道」。

LAYER 4

循环：你每天在用的架构

本层目标：把 MCP 映射到自己每天用的 AI 应用上。

图 5 · Host / Client / Server 实景

AI 应用是 Host：每连一个 server 生成一个专属 client（连接隔离）。本地工具（terminal、文件、浏览器）走 stdio —— 进程管道、零网络开销；远程服务（GitHub、搜索、数据库）走 Streamable HTTP + OAuth。工具调用循环（模型吐 call → 执行 → 回填 → 继续）就是 Agent 页ReAct 循环的协议层实现 —— 概念页讲思想，这页讲管道。

数据层 (JSON-RPC 2.0 + 原语) + 传输层 (stdio 本地 / Streamable HTTP 远程) 两层分离 = 同一套消息格式跑在任何传输上 — 与 HTTP 之于 TCP 的分层思想同源
LAYER 5

生态：事实标准与双刃剑

本层目标：知道 2026 的格局与新的攻击面。

图 6 · 时间线 + 安全清单

2024-11 Anthropic 开源 → 2025-03 OpenAI 支持（放弃自家 Function Calling 孤岛）→ 2025-04 Google 跟进 → 2026 数千个 server 的生态。反面：攻击面也标准化了 —— 工具描述里藏指令（提示注入）、恶意 server 借模型之手（混淆代理）、假确认框钓鱼。缓解三板斧：最小权限、工具白名单、高危操作人工确认。

带走的五句话

  • M×N 集成地狱 → M+N 总线：USB-C 思想，规模越大省得越多（93%）（L1/L2）
  • JSON-RPC 四步：discover → tools/list → 塞 prompt → tools/call（L3）
  • 三原语：Tools 执行 / Resources 读数 / Prompts 模板 + 反向 Elicitation（L3）
  • 两层架构：数据层协议 + 传输层（stdio 本地 / HTTP 远程）（L4）
  • 2026 事实标准，但攻击面也标准化 — 最小权限是纪律（L5）

术语速查

MCP Host / Client / Server
AI 应用（协调者）/ 每 server 一个的连接器 / 提供上下文与工具的程序。
JSON-RPC 2.0
MCP 的消息格式 —— 请求/响应/通知的标准信封。
inputSchema
工具的 JSON Schema 参数声明 —— 模型与 server 之间的合同。
stdio 传输
本地进程间管道 —— 零网络开销，本地工具首选。
Streamable HTTP
远程传输 —— HTTP POST + SSE 流，支持 OAuth 认证。
Elicitation
server 反向向用户要输入/确认 —— 危险动作的刹车片。
提示注入 (prompt injection)
工具描述/返回值里藏恶意指令 —— MCP 时代的新攻击面。
