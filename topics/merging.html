权重空间 · 免训练的多任务

模型合并：权重算术

LoRA 页说微调是「插低秩小卡」—— 那这些小卡能不能当算术对象？能：M_merged = M_base + (M_A − M_base) + (M_B − M_base) —— 两个各自微调的模型逐元素相加，产物还是一个正常模型，同时会两边的技能（Ilharco 2022「任务向量」）。更疯的 DARE：随机丢掉 90% 的增量、剩下的放大 10 倍，性能几乎不降，任务间干扰却除以 100。不训练、零推理开销 —— 最反直觉的一页。

夹角冲突模拟器 DARE 干扰账 约 8 分钟 前置：LoRA · FFN
LAYER 1

奇观：相加还是个模型

本层目标：承认这违反直觉。

图 1 · 任务向量算术的四种运算（node 实测 cos）

定义任务向量 τ = M_ft − M_base（微调权重减基座）—— 「学到的技能」从此是一个向量。四则运算（node 实测，1000 维玩具，两任务不相交支撑）：加 = M+τ_A+τ_B 同时会两技能（合并后与两个任务向量 cos 均 ≈ 0.707 = 1/√2，双保留）；减 = M+τ_A−τ_A 完全遗忘 A（cos(u)→0、cos(v)→1.0）；乘负 = 反学习（论文：降低「不该会」的能力）；缩放 = 技能强度旋钮。神经网络的技能居然生活在近似线性的权重空间里 —— 这是一切合并方法的地基。

认知检查 · LAYER 1

为什么两个模型直接相加不会得到「乱码模型」？

「兼容坐标系」是关键前提 —— 换两个不同基座直接加，确实会得到乱码。L3 看这个前提什么时候破。
LAYER 2

向量：技能的四种操作

本层目标：把「技能」彻底向量化。

图 2 · τ 的操作面板 + LoRA 的同构

LoRA 的 ΔW=B·A 就是一个任务向量（LoRA 页的「插卡」在此获得算术身份）：合并 = 把两张卡的增量都加进基座；多 LoRA 切换 = 基座 + 可插拔 τ。工程现场早已在用：swarm 微调出 N 个小模型再合并（一次训练预算买多个专家）、安全对齐向量可以事后减掉（也解释了为什么对齐能被廉价绕过 —— 反学习在权重空间是减法）。任务向量视角把「技能」从模型文件降维成了一个 N 维数组。

认知检查 · LAYER 2

「减掉任务向量 = 遗忘」这个事实，对对齐安全意味着什么？

任务向量的可逆性是双刃剑：工程上方便，安全上是负债。
LAYER 3

冲突：夹角决定命运

本层目标：看懂合并什么时候失败。

图 3 · 夹角冲突模拟器（拖滑块转 τ_B 的方向，实时算双任务保留）
两任务向量夹角 90°

合并的失败模式全在几何里：夹角 90°（正交）—— 两技能落在不同维度子空间，相加 = 平面叠加，各自保留 1/√2 ≈ 71%（node 实测 0.708/0.706）；夹角变小 —— 支撑重叠，同一维度上两个任务互相踩脚（符号相反直接抵消，符号相同则过冲）；夹角 0° —— 完全冲突，只能留一个。真实模型的任务向量大多近似正交（技能住在一个极高维空间的稀疏角落里，随机方向在高维几乎必然近正交）—— 这就是「直接相加居然能用」的几何解释。

认知检查 · LAYER 3

为什么「高维空间里随机两个方向几乎必然近正交」救了模型合并？

「维度诅咒」的反面 —— 维度祝福。但近亲任务（同为代码任务）方向会刻意相关，冲突仍真实存在 —— L4 的方法就是治这个的。
LAYER 4

方法：四代演进 + DARE 干扰账

本层目标：看懂每代方法治什么病。

图 4 · 线性 → SLERP → TIES → DARE（DARE 干扰账 node 实算）

①线性平均（直接相加/平均）：正交时够用，冲突时互相抵消。②SLERP：球面插值走大圆 —— 权重空间的「中点」不该走直线（范数失真）。③TIES（Yadav 2023）三步仲裁：剪枝（每个模型只留 top 幅度）→ 符号冲突解决（同维符号打架时按总幅度投票，输家清零）→ 平均 —— 治「抵消」。④DARE（Yu 2023）最反直觉：各自随机丢 90% 增量、剩余 ×10 缩放 —— 干扰账（node 实算）：100 个重叠维上，双方同时存活的冲突维期望 = 100×k² ，k=0.1 时只剩 1 个（干扰 ÷100），而论文实测 95 任务性能 ≈ 不降 —— 独立稀疏化让碰撞概率平方衰减，自身的信号靠缩放补回。「让路」比「仲裁」更便宜。

认知检查 · LAYER 4

DARE 随机丢 90% 为什么性能不崩？

注意选项一与正确答案的区别：DARE 是「随机」丢，不是按重要性 —— 妙处正在于不需要知道谁重要。
LAYER 5

账本：三种多任务方案

本层目标：会算多任务的经济学账。

图 5 · 合并 vs 多 LoRA vs 大一统微调

三种「一个模型会 N 个任务」的路线：合并（N 次 LoRA + 一次权重算术，0 额外推理开销，但技能上限受冲突制约）；多 LoRA 路由（运行时换卡，技能无损但每次都要加载/切换，工程复杂）；大一统微调（混合数据训一遍，上限最高但要一次性训练预算 + 数据工程）。mergekit（2024）把合并变成配置文件 —— frankenmerge 文化：开源社区像调酒一样混合模型，OpenRouter 上常驻 merged 系产物。权重空间的可组合性，是开源生态独有的红利 —— 闭源 API 模型你永远做不了减法。

认知检查 · LAYER 5

「合并是开源生态独有的红利」—— 为什么？

开放权重 = 开放了权重空间的一切运算 —— 这是开源与 API 的本质区别之一，不只是「能本地跑」。

带走的五句话

  • 任务向量 τ = M_ft − M_base：加=学、减=遗忘、乘负=反学习、缩放=强度旋钮（L1/L2）
  • LoRA 的 ΔW 就是任务向量 —— 插卡获得算术身份（L2）
  • 正交=无损叠加（各自 1/√2）；高维随机方向几乎必然近正交 —— 合并的几何红利（L3）
  • DARE 随机丢 90%：干扰 ÷100（k² 衰减）＞ 自身损失 ÷10 —— 让路比仲裁便宜（L4）
  • 合并 0 训练 0 推理开销；开放权重 = 开放权重空间的运算 —— 开源独有红利（L5）

术语速查

模型合并 (model merging)
把多个模型的权重按算术规则合成一个 —— 免训练的多任务方案。
任务向量 (task vector)
τ = M_ft − M_base —— 微调学到的技能作为可运算的向量（Ilharco 2022）。
反学习 (unlearning)
减去/乘负任务向量以移除某能力 —— 对齐安全的双刃剑。
SLERP
球面线性插值 —— 两权重的「中点」沿大圆走，保范数。
TIES
剪枝 → 符号冲突仲裁 → 平均 —— 三步治抵消（Yadav 2023）。
DARE
随机丢弃增量 90% + ×1/(1-p) 缩放 —— 干扰 k² 衰减（Yu 2023）。
mergekit / frankenmerge
开源合并基建 / 社区混模文化 —— 权重算术的工程化。
