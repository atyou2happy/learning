Mostik 隐空间桥接

俄罗斯数学家团队的初创公司 Mostik 提出让两个模型跳过文字、直接交换内部状态：753B 的 GLM-5.2 只负责读题（prefill），4B 的 Qwen-3.5 负责写作（decode），中间一座可训练的「桥」翻译隐态。两个模型全程冻结 —— 桥是唯一的学生。

图解 + 数据 2026.09 新技术 约 10 分钟 参考：mostik.ai + WIRED
LAYER 1

瓶颈：每个 token 只让 17 bits 离开模型

本层目标：一张漏斗图，看清「模型想的远多于说的」这个信息瓶颈。

图 1 · 2MB 内态 → 17 bits 输出的信息漏斗

生成一个 token，模型内部先构建 100+ 个隐向量（约一百万个数、~2MB 内部状态），最后只从 15 万词表里选一个 token 输出 —— log₂(150000) ≈ 17 bits，其余全部丢弃，永不再用。两个模型协作时，全部「理解」只能挤过这个针眼。

单 token 信息流出 ≈ log₂(vocab) ≈ 17 bits  vs  内部状态 ≈ 2 MB = 16,000,000 bits  ⇒  压缩比 ~10⁶ : 1 文本交接 = 强迫模型把全部理解压进 17 bits/token，接收方再从这几行字重建整个问题空间

关键认知：今天的多模型系统（Agent 委派、级联、Council）全部通过文本协作 —— 文本是人类接口，不是模型接口。Mostik 的问题：模型之间为什么要说人话？

认知检查 · LAYER 1

为什么说文本交接对模型间协作是「窄带通信」？

瓶颈不是长度也不是速度，是表达力：内部表示是连续高维向量，token 是离散符号。序列化成文字本身就是一次 10⁶:1 的有损压缩。
LAYER 2

证据：隐态里早就有文字没有的东西

本层目标：两个可解释性研究，确认「丢弃隐态 = 丢弃信息」不是猜想。

图 2 · 模型提前规划：写出 a/an 之前，答案已在隐态里

上：选择「a / an」的模型必须提前知道后面的名词 —— 可解释性研究发现表示早在写出前几个 token 就已形成（Hanna & Ameisen, ICLR 2026），且模型越大效应越强；Anthropic 团队在 Claude 3.5 Haiku 里发现同样的机制：写诗前先定韵脚（Lindsey et al., 2025）。

证据一 · 提前规划

Qwen-3 在写出 "an accountant" 前几个 token，隐态里已携带「accountant」的表示 —— 正是它驱动了 "an" 的选择。隐态先于文字、多于文字。

证据二 · 跨模型可译

Mostik 的桥在不微调任何模型的前提下成功翻译 GLM-5.2 → Qwen-3.5 隐态，说明不同团队、不同数据训出的模型，内部表示已天然相似到可互译 —— 桥只是找到了这份既有结构。

认知检查 · LAYER 2

「模型间天然存在可翻译性」的最强证据是什么？

冻结是关键实验设计：模型没被适配到信道上，信息还能通过 —— 说明桥利用的是两个模型本来就有的共享结构，而不是训练硬造的接口。
LAYER 3

桥接：prefill 归大模型，decode 归小模型

本层目标：一张架构图，记住「谁做什么、什么被训练」。

图 3 · GLM-5.2 (753B) — Bridge — Qwen-3.5 (4B)

分工来自推理经济学的不对称：读 prompt 是一次并行 pass（753B 也便宜），写 token 是逐个生成（4B 快而省）。大模型读完题把隐态送上桥就停笔，小模型接过上下文直接开写。

只训桥: LLM₁ (冻结) → Bridge(θ) → LLM₂ (冻结)   ·   θ 是系统中唯一可学习参数 工程意义: 不动两个生产模型的任何权重 —— 升级、回滚、组合都只关系到桥这一层

3.1与熟悉概念的对照

方案桥在哪要重训模型？交接介质
MoE 专家路由训练时长在模型内部要（端到端）内部隐态（天然）
文本 hand-off（Agent 委派）没有桥，靠提示词不要token 文本（17 bits/token）
Mostik 隐态桥外挂翻译层不要（双冻结）隐向量（~2MB/级）
认知检查 · LAYER 3

为什么 Mostik 选择「大模型只读、小模型只写」而不是反过来？

这正是 KV Cache 页讲过的 prefill/decode 不对称：prefill 一次并行可摊薄，decode 逐 token 是持续成本。让贵的算力做便宜的事、便宜的算力做量大的事。
LAYER 4

数字：桥接组合的性价比

本层目标：四个关键数字 + 一条全程占优的曲线。

图 4 · 结果数字墙（mostik.ai 公开实验）

四个数字一套逻辑：桥接组合弥合大小差距的一半；小模型自身准确率 +25%；越难的题提升越大（难题子集 2x）；而达到同等得分只需等效中模型 40% 的算力。

图 5 · 隐态交接 vs 文本交接：全算力区间 Pareto 占优

在每一档「给大模型的算力」下，隐态交接都不差于文本交接；交接越早优势越大（最高 +10pp） —— 因为早期大模型还没写出任何字，文本交接两手空空，隐态里却已积累了读题的理解。

认知检查 · LAYER 4

为什么交接发生得越早，隐态交接比文本交接的优势越大？

文本交接的传输量 = 已写出的字；隐态交接的传输量 = 已形成的理解。交接点越早，两者差距越悬殊 —— 这直接证明隐态携带文字尚未表达的信息。
LAYER 5

落地：部署模式与未解问题

本层目标：两种部署形态 + 冷静的局限清单。

图 6 · 两种部署模式：同机低延迟 / 跨端点传输

模式 A 适配在线服务：重算力花在 prefill 上，token 生成留在快而省的小模型。模式 B 适配可容忍批式延迟的场景：隐态经网络在独立端点间传输，小模型可跑在任何空闲 GPU（含旧卡）上。

5.1未解问题（官网自己承认的）

问题现状
因果性未证实能证明隐态信息「存在且被传过去了」，尚未通过干预实验证明接收方「使用」了它 —— 官网明言这是下一步
桥的泛化一个桥只连一对模型；换模型对需重训桥。不同架构/规模组合的成本尚无公开数据
安全影响绕过语言层 = 绕过基于文本的审查与对齐监控 —— 隐态里传了什么，现有工具看不见
可观测性机会桥接产生三个新对象（发送方隐态/译后隐态/接收方行为），干预-观察可成为新的模型可解释性手段

带走的五句话

  • token 是人类接口不是模型接口：每 token 只放行 17 bits，内部 2MB 理解被丢弃 —— 多模型协作全挤在这根针眼里（L1）
  • 可解释性研究证明隐态先于且多于文字；不同模型的隐态天然可互译 —— 桥是发现结构，不是发明结构（L2）
  • 分工由推理经济学决定：753B 只 prefill、4B 管 decode、桥是唯一被训练的部件，两模型冻结（L3）
  • 数字：弥合差距 50%、小模型 +25%、难题 2x、等效算力 40%；对文本交接全程 Pareto 占优，早期交接 +10pp（L4）
  • 开放问题：因果干预实验未做、桥按模型对重训、隐态传输绕过文本审查 —— 新技术该带新审慎（L5）

术语速查

latent / hidden state
模型内部的连续向量表示。每个 token 伴随约 2MB 的隐态，输出时绝大部分被丢弃。
prefill / decode
读题（并行、一次完成）与写作（逐 token、持续成本）—— 推理成本的不对称来源。
文本 hand-off
多模型系统的传统协作方式：把已生成的文字传给下一个模型。带宽 = 17 bits/token。
冻结 (frozen)
训练桥时不更新任何 LLM 权重 —— 证明桥利用的是模型既有结构。
Pareto 占优
在所有算力档位下性能都不差于对照 —— 不存在「省了这边亏了那边」的权衡区。
