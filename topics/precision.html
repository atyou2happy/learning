浮点精度：FP32 / BF16 / FP8 的比特账

KV Cache 页的 0.5MB/token、Quantization 页的 4bit 压缩、Roofline 页的 989 TFLOPS —— 这些数字全都站在一个从未验明正身的常数上：一个参数占几个字节、一次乘法按什么精度算。这一页打开它：1 符号位 + 8 指数位 + 7 尾数位 = bf16 —— 训练界的不速之客，赢的原因是「砍精度、保范围」。0.1 在 bf16 里其实是 0.10009765625，而模型毫不在乎。

LAYER 1

单位：那个「×2 字节」从哪来

本层目标：把全站数字的单位审判一遍。

图 1 · 五种格式的比特结构 + 全站单位对账

浮点数 = 符号位 + 指数位（范围）+ 尾数位（精度）。KV Cache 页的 0.5MB/token：2(K+V) × 32头 × 4096维 × 2 字节(fp16) —— 那个 2 就是本页的主角。同一份缓存 int8 存 = 0.25MB、int4 = 0.125MB（Quantization 页四旋钮的来历）。8B 模型权重：fp16 16GB → int8 8GB → int4 4GB，每降一档，字节减半 —— 显存、带宽、TFLOPS 全部跟着这个刻度走。

图 2 · 精度放大镜（切格式看 1.0 附近的可表示点）

1.0 附近的步长（node 实算）：fp32 = 1.2e-7 · fp16 = 9.8e-4 · bf16 = 0.0078（1.0 的下一个点是 1.0078125）· fp8-E4M3 = 0.125。注意 int8 的格子均匀，浮点的格子越靠近 0 越密 —— 对数刻度。0.1 存进 bf16 变成 0.10009765625（误差万分之一）—— 模型对这个量级的误差毫不在乎，因为它统计的不是某一个数。

丢精度的代价是噪声，丢范围的代价是死亡 —— 下一层看两种死亡。
LAYER 3

训练：bf16 为什么赢了 fp16

本层目标：看懂两种「直接丢数」的死亡方式。

图 3 · 梯度生死簿（点按钮切换格式）

典型小梯度 1e-8：fp16 最小正常数 6.1e-5 —— 直接下溢归零，梯度永久丢失；bf16 最小正常数 1.2e-38 —— 活得好好的。上溢端：fp16 最大 65504，一层激活突然变大就 inf → NaN，loss 尖峰炸训练。bf16 与 fp32 共享 8 位指数，范围一个不丢、精度砍到 8 位 —— 大数小数都死不了，只是粗糙。混合精度 = 主权重 fp32（累积精度）+ 前向/反向 bf16（速度），两边的好处全占。fp16 也救得活：loss scaling 先把 loss ×1024 再反传 —— 但 bf16 免去了这一步，2018 年后训练界几乎一边倒。

认知检查 · LAYER 3

「bf16 精度比 fp16 低却赢了训练」—— 关键洞察是？

「宁可粗糙、不可死亡」—— 范围是底线，精度是奢侈品。B200 把这条推到 FP4 也是同一赌注。
LAYER 2 → 4

推理：FP8 的两种格式与 int8 的格子

本层目标：会选推理档位。

图 4 · 同样 1 字节的两种存法：int8 vs FP8

int8：均匀格子，配 scale/zero-point 把权重区间线性映射（Quantization 页讲过怎么算）；FP8-E4M3：对数格子，近 0 密、远处疏 —— 权重分布尖峰在 0 附近，对数格子天然合身。E4M3（max 448）管前向，E5M2（范围大 57344）管梯度 —— 推理只需前者。KV Cache 同理可压：int8 = 半价、int4 = 四分之一价，代价是长上下文检索精度 —— 省字节的每一档都在和「格子够不够密」做交易。

认知检查 · LAYER 4

同样 1 字节，什么时候 FP8 打得过 int8？

int8 的 scale 是全局折中：尖峰和长尾只能顾一头。FP8 的指数位让格子自己伸缩 —— 分布形状决定胜负。
LAYER 5

价签：精度档位就是价格档位

本层目标：会读硬件表和 API 报价单的精度档。

图 5 · 精度阶梯：每降一档，算力翻倍、显存减半

H100 dense：fp32 67 → bf16 989 → fp8 1979 TFLOPS；B200 再加 fp4 = 9 PFLOPS —— 硬件按比特宽度定制乘法器，比特减半、吞吐翻倍。DeepSeek-V3 用原生 FP8 训练：激活显存对 bf16 减半、算力翻倍 —— 558 万美元训练账（Pretraining 页）里有它的功劳。这就是 Roofline 页的天花板随精度移动、Quantization 页的 PPL 代价表、MoE 页FP8 提及的共同底层：精度是一根刻度尺，全站的 GB 和 TFLOPS 都印着它的刻度。

认知检查 · LAYER 5

为什么每降一档精度，TFLOPS 就翻倍？

物理账：同样一颗芯片、同样一度电，精度档位决定它每小时能做多少乘法 —— 这就是 B200 押注 FP4 的原因。

带走的五句话

  • 浮点 = 符号 + 指数(范围) + 尾数(精度)；bf16=1+8+7，fp16=1+5+10（L1）
  • 全站数字的单位来源：fp16 2字节 → KV 0.5MB/token；每降一档字节减半（L1）
  • bf16 赢训练的原理：范围保命（grad 1e-8 在 fp16 下溢归零）、精度只是噪声（L3）
  • int8 均匀格子 vs FP8 对数格子 —— 分布形状决定 1 字节存哪种（L4）
  • 精度档 = 价格档：比特减半 → TFLOPS 翻倍 + 显存减半（H100 67→989→1979）（L5）

术语速查

fp32 / 单精度
1+8+23 = 4 字节 —— 传统科学计算默认，训练中只做主权重与累加。
bf16 (bfloat16)
1+8+7 = 2 字节 —— 截短的 fp32：指数原封不动、尾数砍到 8 位。Google 2018 为 TPU 引入，训练事实标准。
fp16 (half)
1+5+10 = 2 字节 —— 范围 ±65504、minNormal 6.1e-5，推理档位、早期混合精度主力。
FP8-E4M3 / E5M2
1 字节浮点两种分法：E4M3 精度高范围小（前向/权重），E5M2 范围大（梯度）。OCP 标准，Hopper 起原生支持。
minNormal (最小正常数)
规格化数的最小值 —— 比它小就落入 subnormal/下溢区，fp16 的 6.1e-5 是梯度杀手。
loss scaling
fp16 训练的救命术：loss 乘大系数把梯度抬进表示范围，更新前再除回。
混合精度 (mixed precision)
fp32 主权重 + 低精度计算的分工 —— 累积精度与速度兼得。
下溢 / 上溢 (underflow / overflow)
超出最小/最大可表示数 —— 前者悄悄归零，后者 inf→NaN 炸训练。
