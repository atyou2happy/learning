Reasoning：推理模型

同一道题：直接答 8×7=54 ✗，先写四步思考再答 56 ✓ —— 模型没换，换的是「允许先想多久」。o1/R1 开启的范式：把更多计算搬进推理期，用思考 token 换准确率。同一基座 AIME 15.5% → 79.8%，没人教过任何解题步骤。

思考预算滑块 R1 配方动画 约 10 分钟 前置：采样策略
LAYER 1

现象：计算搬进上下文

本层目标：看清「直接答」与「先思考」的差异不是模型能力，而是计算位置。

图 1 · 同一道题，两种模式

CoT 的本质：每生成一个思考 token，模型就多做一次完整 forward（回忆 KV Cache 页：每 token 都要在全部历史上做 attention）。串行思考 = 给模型深度——中间结果写进上下文，后面的 forward 能「读到」它。这不是魔法，是把原来一次 forward 装不下的计算摊开成 N 步。

认知检查 · LAYER 1

为什么「先想再答」能解决直接答会错的题？

参数全程冻结。变的是「有效计算量」：一步 forward 的深度有限，N 步串行 = N 倍深度 + 显式记忆。这就是 test-time compute scaling 的全部含义。
LAYER 2

R1 配方：没人教，自己学会

本层目标：记住四阶段流水线，以及最反直觉的一点 —— 反思不是教出来的。

图 2 · DeepSeek-R1 四阶段配方

奖励设计极简：答案对 +1、格式对 +1，仅此而已。但 71% (R1-Zero 纯 RL) 的成绩说明：只要奖励信号足够干净，「检查、回溯、换个思路」这些策略会自己长出来——因为它们真的提高答对率。SFT 冷启动（阶段1）只是为了解决可读性和语言混杂，不是教推理。

认知检查 · LAYER 2

R1-Zero（跳过 SFT 直接 RL）暴露的主要问题是什么？

R1-Zero 的 AIME 71.0% 证明纯 RL 就能涌现推理；SFT 冷启动解决的是表达层。二者分工不同 —— 这是「配方」二字的意义。
LAYER 3

aha moment：涌现的反思

本层目标：理解训练曲线上那根「突增」是什么，为什么它标志性。

图 3 · 训练步数 vs 平均思考长度

RL 中期，模型开始自发写出「等一下，让我重新想想」—— 论文称之为 aha moment。此刻没人给它示范过「反思」这个词的用法。与此同时思考长度激增：模型发现「多想 = 更可能对 = 更多奖励」，于是自己拉长了自己的思考。这一刻是「推理策略从奖励中涌现」的直接证据。

奖励 = 1[答案正确] + 1[格式合规] · 无过程奖励 · 无人工演示 过程奖励 (PRM) 需要人工标注每步对错 —— R1 证明结果奖励 (ORM) 已足够让过程策略涌现
LAYER 4

预算：对数线性的收益，线性的成本

本层目标：拖动滑块，找到「性价比拐点」的直觉。

图 4 · 准确率 vs 思考预算（拖动滑块）
8k tok

绿线：预算 ×16 → 准确率 +14pp（对数线性，示意曲线，渐近 R1 的 79.8%）；红虚线：成本严格线性。两条线的张口就是性价比的流失 —— 4k→32k 花八倍钱换 10.5pp，而 512→4k 花 8 倍换 10.5pp 之外还从 58.8% 起步。工程上的含义：默认预算设在曲线「膝盖」处（本例 ~8k），难题再放宽。

认知检查 · LAYER 4

R1 官方为什么推荐 T=0.6 而不是 T=0？（采样页的进阶应用）

这是「贪心重复陷阱」的高级版：普通回答重复几个词无伤大雅，思考链重复 = 整段推理报废。0.5-0.7 的温度给反思留出岔路的可能。
LAYER 5

落地：思考的账单与路由

本层目标：算清一次深度思考的真实开销，并知道何时该关掉它。

图 5 · 20k 思考 token 的账单（13B 模型）

思考的 KV Cache 是权重的 59% —— Continuous Batching 页的每请求显存翻倍、量化页的 KV int8/int4、PagedAttention 的按页回收，三条防线在这里全部用上。API 计费同理：思考 token 照单全收。

场景建议
数学 / 代码 / 规划难题开思考，预算给足（8k-32k）—— 对数线性前段收益最肥
简单问答 / 翻译 / 文案关思考或低预算 —— 曲线在 easy 任务上饱和更早，白花钱
混合流量（服务端）easy/hard 路由：小模型先判断难度，再决定给不给思考预算 —— 类似 Mostik 的协作思路
蒸馏替代固定场景可用蒸馏版（R1-Distill 72.6% > 同尺寸自 RL）—— 把思考模式烧进权重，推理时少付账单
参数速查thinking budget / max_thinking_tokens / reasoning_effort=low|medium|high（各平台命名不一）

带走的五句话

  • 思考 = 把计算搬进上下文：参数不变，串行 forward 换深度（L1）
  • R1 配方四阶段：SFT 冷启动只是表达层，推理策略从结果奖励中涌现（L2）
  • aha moment：没人教反思，它是「答对拿奖励」的副产品（L3）
  • 收益对数线性、成本线性 —— 预算设在曲线膝盖处，难题再放宽（L4）
  • 20k 思考 KV = 权重 59%；easy/hard 路由 + 蒸馏是两把省菜刀（L5）

术语速查

CoT (Chain-of-Thought)
把中间步骤写成文本再作答 —— 推理模型的前身（prompt 技巧版）。
test-time compute
推理期多花计算换质量 —— 与训练期 scaling 并列的第二条 Scaling Law。
GRPO
组相对策略优化：同题采样一组，以组内相对优势估计基线 —— 省掉价值网络。
ORM / PRM
结果奖励（只看答案）vs 过程奖励（每步打分）。R1 证明 ORM 足以涌现过程策略。
蒸馏 (distill)
用大推理模型的思考轨迹 SFT 小模型 —— R1-Distill 系列，便宜且不掉太多。
thinking budget
限制思考 token 上限的参数 —— 超出即强制作答，性价比拐点的工程旋钮。
