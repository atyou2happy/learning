Speculative Decoding

decode 逐 token 爬行，GPU 算力大量空转 —— 因为一次 forward 只为产出 1 个 token。投机解码的赌局：小模型先连猜 γ 个，大模型一次 forward 并行验证全部 —— 猜对白赚，猜错回退。数学上与原模型逐 token 生成完全等价，却快 2~4 倍。

验证游戏 加速比曲线 约 11 分钟 前置：KV Cache
LAYER 1

喂不饱的 GPU：算力与产出严重失衡

本层目标：看清 decode 阶段「一次 forward 一个 token」的浪费本质。

图 1 · 标准 decode vs 投机 decode 的算力利用

大模型 forward 一次的算力足够同时算几十个位置 —— 标准解码只用它算 1 个，其余浪费。验证 γ 个草稿 token 与生成 1 个的算力几乎相同（并行矩阵乘），猜中的每一个都是白赚。

认知检查 · LAYER 1

为什么验证 4 个草稿 token 不会比生成 1 个慢多少？

这就是 prefill 快 decode 慢的镜像（KV Cache 页讲过的不对称）：并行度才是关键。投机解码本质是把 decode「伪装」成一小段 prefill。
LAYER 2

赌局：起草 → 验证 → 收割或回退

本层目标：亲手玩三轮验证游戏，建立「接受前缀 + 免费纠正位」的直觉。

图 2 · 核心验证游戏（点击按钮逐步推进：起草 → 验证 → 下一轮）

三轮结束看记分牌：9 个 token 只用 3 次目标 forward（3.0 token/forward）。绿格 = 接受的草稿；紫格 ◄ = 猜错处大模型亲自纠正的位置（照收！）；红格 = 被丢弃的错误草稿。注意每轮保底产出 1 个 token —— 最坏情况也不亏算力，只亏草案时间。

每轮产出 ≥ 1 (验证位) + 接受数 n · 墙钟 = 1 次目标 forward + γ 次廉价草案 最坏情形（全猜错）：产出 1 个 token，多花 γ 次小模型 forward —— 代价有界，收益无界
认知检查 · LAYER 2

「免费纠正位」是什么意思？

验证 forward 计算的是「每个位置若由我来生成，下一个 token 是什么」—— 猜错位置的答案恰好是这个计算的副产品。所以每轮产出 = 接受数 + 1，永不空手。
LAYER 3

数学：接受率决定一切，γ 有最优值

本层目标：一条公式 + 一组曲线，理解加速比的上限与 γ 的权衡。

E[每轮产出] = 1 + α + α² + … + α^γ = (1−α^(γ+1)) / (1−α)   ·   加速比 S ≈ E[产出] / (1 + γ·c) α = 单 token 接受率（几何分布假设下）；c = 草案模型成本比（取 0.05）。α 是唯一命门：草案越像目标，α 越高
图 3 · 加速比曲线：α 三档 × γ=1..8（圆点 = 各自最优 γ）

α=0.8 时最优 γ≈8、S=3.09x；α=0.7 时 γ=5-6 就到顶（2.35x）。曲线会掉头：γ 太大时草案质量下降 + 错误草稿浪费验证算力 —— 这就是「投机」的真实成本曲线。实测锚点：EAGLE-2 报 2.7-3.7x，DeepSeek MTP ~1.8x，与本公式 α=0.8, γ=4 → 2.80x 同量级。

认知检查 · LAYER 3

草案模型很弱（α=0.5）时，为什么加大 γ 反而更亏？

α=0.5 时连续猜对 4 个的概率只有 6%。草案成本是「每轮必付」的，收益却按几何分布衰减 —— 期望值算不过来就收手。
LAYER 4

无损：这不是量化，是数学等价

本层目标：理解拒绝采样如何保证输出分布与原模型完全一致。

图 4 · 拒绝采样：接受与拒绝都落在原模型的分布里

草案命中高概率 token → 大概率直接接受；命中冷门 → 大概率拒绝并由大模型亲自出 token。两种结局的合成分布恰好等于目标模型自己的分布 —— 逐 token 对比与不开投机时完全一致。

接受概率 min(1, p(x)/q(x)) · 拒绝时按 p(x)−q(x) 重采样 ⇒ 最终分布 ≡ p(x) 这就是「lossless」的严格含义 —— 区别于量化(改数值)或蒸馏(改模型)，投机解码不改任何概率
认知检查 · LAYER 4

为什么说投机解码是「无损」而量化是「有损」？

小模型只影响「猜什么」，不影响「最终分布是什么」—— 它是提案者，不是决策者。决策权始终在目标模型的分布里。
LAYER 5

家族与落地：从外挂起草到长在模型身上

本层目标：认全四代变体 + 知道生产参数怎么调。

图 5 · 变体家族演进

趋势：起草器从「独立小模型」（外挂、慢、α 低）→「多头并行」（Medusa）→「特征层树搜索」（EAGLE，α 高）→「训练时就内建」（MTP，零额外部署）。草案质量每上一档，加速比跟着上一档。

num-speculative-tokens每轮起草长度 γ常用 3-5，按接受率调

带走的五句话

  • decode 一次 forward 只产 1 token，算力喂不饱 —— 验证 γ 个与算 1 个墙钟几乎相同（L1）
  • 赌局结构：小模型起草 → 大模型并行验证 → 接受前缀 + 免费纠正位，最坏也保底 1 token（L2）
  • 加速比 S 由 α（接受率）决定，γ 有最优值：草案差时收手，草案好时加注（L3）
  • 拒绝采样保证输出分布与原模型数学等价 —— 无损，不同于量化/蒸馏（L4）
  • 四代演进：外挂 → Medusa 多头 → EAGLE 特征层树 → MTP 训练内建；实测 2-4x（L5）

术语速查

draft model / 草案模型
便宜的小模型，负责猜。可以独立（经典）、多头（Medusa）、特征层（EAGLE）或内建（MTP）。
γ (gamma)
每轮起草的 token 数。存在最优值：太小赚不满，太大草案质量崩。
α (接受率)
草稿 token 被目标模型接受的概率。几何分布假设下连续接受率约为 α^n。
拒绝采样 (rejection sampling)
按 min(1, p/q) 接受、拒绝时按残差分布重采的机制 —— 无损性的数学来源。
MTP (Multi-Token Prediction)
训练时就让模型预测未来多个 token 的头，推理时直接当起草器（DeepSeek-V3）。
