ViT / CLIP

Transformer 吃 token 序列，图像是 224×224×3 = 150,528 个数字的像素立方体 —— 中间缺一个「图像版的 BPE」。ViT 的答案是切 patch；CLIP 再进一步：4 亿图文对把猫的图片和「a cat」拉进同一个向量空间。GPT-6 Astra「看屏幕」的每一步，都建立在这两块地基上。

patch 切分滑块 CLIP 相似度矩阵 约 10 分钟 前置：Tokenizer
LAYER 1

鸿沟：token 序列 vs 像素立方体

本层目标：看清文本和图像进入模型前的形态差异。

图 1 · 模型想要的 vs 图像给的

文本经过 Tokenizer 页的 BPE 变成语义单元序列；图像的像素没有「词」—— 每个数字只是亮度采样，没有语义边界、没有天然顺序。CNN 时代用局部卷积绕过这个问题；Transformer 时代必须正面回答：图像的最小语义单元是什么？

认知检查 · LAYER 1

为什么不能把 150,528 个像素直接当 15 万个 token 喂给 Transformer？

两个原因叠加：计算上 N² 爆炸（FlashAttention 页），语义上单像素太「碎」。patch = 在计算与语义之间的折中粒度。
LAYER 2

ViT：把图像切成「句子」

本层目标：拖动滑块，建立 patch 大小 ↔ token 数量的手感。

图 2 · patch 切分（拖动滑块换 patch 大小）
16×16

224×224 图像按 16×16 切 → 14×14 = 196 个 token，每个 patch 拉平成 768 维向量（16·16·3=768，恰好等于 ViT-Base 的 hidden size —— 经典选择的巧合之美）。滑到 8×8 有 784 token（细但贵），32×32 只要 49 个（便宜但糊）。加位置嵌入后，图像就成了一段「196 个词的句子」。

N_tokens = (H/P) × (W/P) · 每 token 维度 = P²×3 · 序列再补一个 [CLS] patch 大小是视觉版的「词表粒度」：小 patch = 细粒度高成本，大 patch = 便宜但损失细节
LAYER 3

CLIP：图文同空间

本层目标：看懂双塔对比学习 —— 4 亿图文对的魔力。

图 3 · 双塔对比学习与相似度矩阵

两座独立的塔：图像塔（ViT）和文本塔（Transformer），各自把输入编码成向量。训练目标（InfoNCE）只做一件事：让配对的图文相似度高（对角线绿格），不配对的低（红格）。batch=32768 时一次要对比 10.7 亿个负样本对 —— 没有人工标注，网页上的天然图文对就是免费教材。这正是 RAG 页余弦相似度的多模态版：同一个空间，才能比距离。

认知检查 · LAYER 3

为什么说 CLIP 的训练信号「免费」？

自监督的精髓：世界本身已经标注了哪段文字配哪张图。CLIP 只是把这个天然配对变成了对比学习的正样本。
LAYER 4

零样本：现写候选就能分类

本层目标：理解 CLIP 为什么不需要训练就能认新东西。

图 4 · 零样本分类：一张从没见过的狐狸照片

把候选类别写成句子（「a photo of a fox」…），各编码成向量，与图片向量算余弦 —— argmax 即分类。模型没上过一节分类课，ImageNet 零样本 76.2%。细节：候选文本本身是超参 —— 加一句「a type of animal」能再 +3pp（prompt 工程的 CLIP 版）。这个「现写候选」的能力，正是 GPT-6理解屏幕上任意按钮和菜单的基础。

图 5 · GPT-6 看屏幕的视觉 token 账单

同一眼 1080p 屏幕：patch 14 → 10,764 token，缩图 + patch 28 → 576 token，18.7 倍差距。计算机使用 agent 每一步都要「看一眼」，视觉 token 是它最大的隐形成本（对照 GPT-6 页的成本悖论）。缩图/大 patch 牺牲小字识别换速度 —— 和 Reasoning 页思考预算一样，是精度与成本的旋钮。

LAYER 5

落地：VLM 通用配方

本层目标：记住三段式配方，看懂所有多模态模型的视觉通路。

图 6 · 视觉语言模型 = 三段流水线

视觉编码器（ViT，常直接用 CLIP 预训练的）→ 投影层（把视觉向量对齐到 LLM 的词向量空间，MLP 或 Q-Former）→ LLM 主干（视觉 token 与文本 token 混排，对它来说没区别）。GPT-4V / Gemini / Astra 的视觉通路都是这三段 —— 差异只在各段的尺寸与训练策略。

带走的五句话

  • 图像没有「词」：150,528 个像素 vs token 序列 —— 缺图像版 BPE（L1）
  • ViT 切 patch：16×16 → 196 token，patch 大小 = 粒度与成本的旋钮（L2）
  • CLIP 双塔对比：4 亿免费图文对，10.7 亿负样本对一次训练（L3）
  • 零样本 76.2%：现写候选文本就能分类 —— 候选也是超参（L4）
  • VLM 三段式：编码器 + 投影层 + LLM —— GPT-6「看屏幕」的全部地基（L5）

术语速查

ViT (Vision Transformer)
把图像切 patch 当 token 序列处理的 Transformer —— 视觉编码器的事实标准。
patch
图像的最小处理单元（典型 14²/16² 像素）—— 图像版的「词」。
CLIP
对比图文预训练（Contrastive Language-Image Pretraining）—— 双塔共享一个向量空间。
InfoNCE
对比学习损失：正样本拉近、负样本推远，温度 τ 控制尖锐度。
零样本 (zero-shot)
不训练任何参数，仅靠候选文本编码 + 余弦最近邻完成分类。
投影层 / Q-Former
把视觉向量对齐到 LLM 词向量空间的适配模块 —— 多模态的「翻译官」。
视觉 token
patch 编码后的序列成员 —— 视觉账单的计量单位（对照 Tokenizer 页）。
